**实现要点**

- 接口：`/sns/oauth2/access_token|refresh_token`、`/sns/userinfo`、`/sns/auth`、`/sns/jscode2session`、`/cgi-bin/token`。
- 信封：`errcode != 0` → `WechatError::Api`；令牌失效码 40001/40014/42001/42002/42007/42009（`is_token_invalid`）。

- `login_with_user_info` 静默授权（`snsapi_base`）失败**不致命**：`user=None` + `user_info_error` + `warn_once!`。
- 凭据脱敏：`AppSecret`/`access_token`/`refresh_token`/`session_key` 的 `Debug` 输出 `***`。
